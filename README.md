# text-token-generator

A Vite-powered Vue 3 + TypeScript app for experimenting with text token controls and previewing generated output.

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Run tests:

```bash
npm run test
```

Run TypeScript checks:

```bash
npm run typecheck
```
